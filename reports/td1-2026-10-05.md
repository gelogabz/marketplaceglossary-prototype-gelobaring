## Suggested (score 2, optional)

#### AWS Brazil 2P Distribution Program — AWS (new_term)
- Non-Brazilian ISVs can grant AWS Brazil distribution authorization so AWS Brazil becomes local seller of record — creating private offers, setting buyer pricing, auto-generating BRL invoices, handling withholding tax — no local Brazilian entity needed. Niche/single-country but a distinct named mechanism, not just a region-availability bump.
- Source: https://aws.amazon.com/about-aws/whats-new/2026/10/aws-brazil-software-license-distribution/

#### Attributed Revenue Dashboard (AWS Partner Analytics) — AWS (updated_term)
- `PRM Resource Tagging — AWS` currently only name-drops this dashboard in passing (added Aug 31). New detail: it's fed by all three PRM measurement methods (tagging, User Agent String, Marketplace Metering), and starting 2027 attributed-revenue measurements determine AWS Partner funding benefits — material enough to either expand that mention or split into its own term.
- Source: https://aws.amazon.com/blogs/apn/unlock-revenue-insights-in-the-new-attributed-revenue-dashboard/

#### AWS Data Competency — AWS (new_term)
- New competency categories (Databases for Services Partners; Relational Databases for Software Partners) plus performance-based "Signature" benefits. No standalone term exists — only generic "AWS Competency"/"AWS Competency Program" umbrella terms.
- Source: https://aws.amazon.com/blogs/apn/new-categories-and-benefits-for-aws-data-competency-partners/

#### Future-Dated Agreements — AWS (new_term)
- Lets a buyer sign a renewal before the current AWS Marketplace contract ends (e.g. sign in December for a January expiry) — only works if auto-renewal is switched off first. Distinct named mechanic, not a rephrase of an existing renewal term.
- Source: https://www.suger.io/resources/blog/aws-marketplace-future-dated-agreements/
